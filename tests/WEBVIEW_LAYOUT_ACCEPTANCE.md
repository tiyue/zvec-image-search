# Windows WebView 布局验收

在正式打包前，以 Windows 显示缩放 100% 分别将软件窗口调整为下列客户区尺寸。每档尺寸保存搜索页、图库任务页和批量标签页截图。

| 窗口尺寸 | 搜索页 | 批量标签画廊 |
|---|---|---|
| 2559×1398 | 固定 15 张，5×3，铺满画廊 | 32 张，8×4 |
| 1920×1080 | 固定 15 张，5×3，铺满画廊 | 15 张，5×3 |
| 1600×900 | 固定 15 张；不足空间时页面内滚动 | 10 张，5×2 |
| 1440×900 | 固定 15 张；不足空间时页面内滚动 | 8 张，4×2 |

## 搜索页

1. 工具栏下方不存在独立结果摘要栏，画廊标题显示“相关图片 · N 张”。
2. 一页最多渲染 15 张；首页、上一页、页码输入、下一页和末页可用。
3. 翻页时旧卡片保留到新页返回，窗口不出现长时间空白或假死。
4. 双击缩略图由 Windows 默认程序打开原图。
5. 点击“所在文件夹”后，资源管理器选中对应原图。
6. 搜索中、无可靠结果、失败和取消均在状态胶囊中可见。

## 图库任务页

1. 上方策略卡和任务创建区保持可见，下方工作区吃满全部剩余高度。
2. “运行任务与历史”和“操作日志”宽屏并排；窄屏上下排列且各自可滚动。
3. 两张表各自分页，超过 1,000 条时不一次渲染全部记录。
4. 选择“智能标注”后显示范围、1～10,000 上限、预算、估算和外部处理确认。
5. `all` 范围未额外确认时不能提交；切换非 AI 任务后确认状态被清除。

## 批量标签页

1. 文件夹、画廊、标签编辑三栏填满剩余高度，不出现页面底部大块空白。
2. 页容量与上表一致；窗口缩放后保留当前第一张图片的位置。
3. 小窗口使用可滚动画廊，不压缩图片到不可辨认。
4. 双击缩略图调用 Windows 默认程序打开原图。
5. 空图库根节点显示 0 张并可选中，不生成可操作的空文件夹条目。

验收只使用临时图库；文件夹删除测试不得指向真实图库、配置目录、缓存、失败图片或搜索结果目录。
