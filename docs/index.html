从“找到图片”到真正管好图库

不是另一个文件浏览器，而是一套覆盖检索、标注、审核、整理和迁移的完整桌面工作流

多模态与跨图库搜索

支持文字、图片、图文联合和模糊标签检索。多个 Collection 可以统一召回、去重和排序；置信度低于阈值的结果不会为了凑数而返回。

可估算、可缓存的智能标注

使用 qwen3-vl-flash 生成真人、Cosplayer、角色、作品、服装和场景等结构化标签。运行前可估算候选数、缓存命中、Token 与费用；已有当前标注会自动跳过。

文件夹驱动的批量标签

按图库、根目录和文件夹筛选，多选图片后批量添加、移除或替换多个标签。人工、文件夹、模型和继承标签都有来源标识，并支持撤销最近一次批量操作。

相似分组与别名治理

利用 SHA-256、感知哈希和已有向量整理重复图、近似图与内容相似图。可维护“雷电将军 / 雷神 / 影”等别名关系，并只在安全身份类别中进行整组传播。

面向大图库的后台任务

分页读取、有界队列、磁盘结果集和批量写入避免一次装入全部数据。搜索优先于长任务；单图失败会跳过并记录，不会让整批索引或标注直接终止。

可恢复迁移与安全清理

设置页集中处理路径重绑、Schema 迁移和旧工作区兼容，已有向量无需重新生成。文件夹删除采用预览、暂存、数据库提交、最终清理的两阶段流程。

一套界面，覆盖完整图片工作流

搜索、后台任务、批量整理与设置迁移各司其职，长任务不占用界面线程

搜索结果只加载当前页

输入任意正整数决定本次搜索数量。结果按置信度为主、原始分数为辅排序，默认每页显示 15 张；双击打开原图，也可以定位文件夹、复制、多选和导出。

三步建立可持续维护的图库

先小批量验证配置和费用，再逐步扩展到完整图库

01

创建图库并确认数据边界

选择原图目录、Workspace 和结果目录，配置阿里云百炼 API Key。路径会进行安全校验，凭据不会写入 JSON、前端或日志。

02

增量索引，按需智能标注

先用 qwen3-vl-embedding 建立可复用的本地向量索引，再决定是否运行独立智能标注。标注可先估算费用，缓存命中不会重复调用模型。

03

搜索、整理并持续学习

跨图库搜索后批量整理标签、别名和相似分组。相关/不相关反馈保存在本机，候选排序必须通过固定评测门禁才能启用。

前端轻交互，后端重任务
Windows 原生运行

Zvec 将窗口与业务彻底分层：Vue 负责界面，pywebview 管理 Windows 窗口与生命周期，Python 原生后端负责检索、模型调用、任务调度和持久化。用户运行时不需要 Docker、Node.js、PowerShell、.NET 或单独安装 Python。

Vue 3 + TypeScript + Vite

搜索、任务、批量标签、学习评测和设置迁移采用组件化前端；发布包只携带编译后的静态资源。

Python + Zvec + SQLite WAL

Zvec 保存图片向量；SQLite 承担图片状态、标签、分页结果、任务历史、结构化日志、本地学习和可恢复写入。

有界并发 + Outbox 恢复

每个图库保持单写入者，不同图库可并行；队列满时返回可重试状态。Collection 写入异常后可从 Outbox 恢复，已有向量不必重新生成。

current_architecture.py 
class ZvecDesktop:
    # 显示层：只负责界面与交互
    frontend = [
        "Vue 3.5",
        "TypeScript 5.9",
        "Vite 8"
    ]

    # Windows 窗口与本地网关
    desktop_shell = "pywebview + WebView2"
    backend = "Python 3.10+"

    # 本地持久层
    storage = [
        "Zvec Collection",
        "SQLite WAL",
        "Collection Outbox"
    ]

    # 按需调用阿里云百炼
    embedding = "qwen3-vl-embedding"
    auto_tag = "qwen3-vl-flash"

    # 发布目标
    target = "Windows x64"

本地优先，不做
模糊的隐私承诺

Zvec 的本地与云端边界是明确的：日常文件管理、标签搜索、分页查看、日志、学习反馈和多数整理操作在本机完成；需要模型理解图片时，相关图片或查询内容会发送到你配置的阿里云百炼服务。

  • 原始图库位置由你决定，删除软件不会自动删除原图
  • 已有向量可重复使用，迁移 Schema 和重绑路径无需再次调用模型
  • 智能标注前显示候选、缓存、Token 与费用估算，全部重跑需要额外确认
  • 日志会清理密钥、Token、Cookie、密码、图片数据和完整模型输入输出
  • 模型、预算、并发和结果目录都可以在设置页集中维护
