从“找到图片”到真正管好图库

不是另一个文件浏览器，而是一套覆盖检索、标注、审核、整理和迁移的完整桌面工作流

▧

Sony A7M4 ARW 快速选片

项目化导入 ARW、JPG 与 PNG，使用缩略图、相机内嵌 JPEG 和完整预览渐进加载。支持评级、色标、筛选、双图对比和原文件导出，不改写源图。

⌕

多模态与跨图库搜索

支持文字、图片、图文联合和模糊标签检索。多个图库可以统一召回、去重和排序；置信度低于阈值的结果不会为了凑数而返回。

✦

图片推荐与向量多样性

每批从技术质量、低曝光和随机发现中组合图片，并避开近期已看内容。多样性只复用现有索引向量，不额外调用模型。

✎

可估算的智能标注

使用 qwen3-vl-flash 生成真人、Cosplayer、角色、作品、服装和场景等结构化标签。运行前可估算候选数、缓存命中与费用；已有标注自动跳过。

↻

自动增量索引与标注

开启图库监控后，新增、修改和删除会进入持久化变更队列，只处理发生变化的文件；新增或修改的图片可自动完成索引与智能标注，无需反复全盘扫描。

◫

文件夹名生成与批量标签

先预览文件夹名生成的标签，再应用到当前文件夹或整个图库；规则会过滤数量、容量等噪声，不调用模型或重建向量。也可批量增删、替换标签并撤销。

✓

本地反馈学习与质量回退

可将结果标记为相关或不相关，并选择是否记录打开、复制与导出行为。反馈保留在本机且不调用模型；候选排序必须通过固定评测，异常时自动回退。

◎

相似分组与别名治理

利用 SHA-256、感知哈希和已有向量整理重复图、近似图与内容相似图。可维护别名关系，并只在安全身份类别中进行整组传播。

⏻

登录常驻与安全退出

安装版在当前用户登录后隐藏启动；关闭窗口只隐藏界面，后台任务、局域网服务和图库监控继续运行。再次启动会唤醒已有窗口，完整退出前会检查活动任务。

☷

面向大图库的后台任务

分页读取、有界队列、磁盘结果集和批量写入避免一次装入全部数据。搜索优先于长任务；单图失败会跳过并记录，不会中断整批。

⌂

可恢复迁移与安全清理

设置页集中处理路径重绑、Schema 迁移和旧工作区兼容，已有向量无需重新生成。文件夹删除采用预览、暂存、提交、清理的两阶段流程。

手机端局域网查看，
电脑负责计算

Android 平板或手机可以在同一局域网内搜索 Windows 电脑上的图库、翻页查看结果，并打开或保存原图。电脑继续负责图库、索引和模型，手机端不会修改设置、建立索引或删除图库。

1
启用局域网服务在 Windows 曜镜设置中选择私网 IP，保存并启用服务。
2
安装 Android 查看端安装 APK，让设备与电脑连接同一 Wi-Fi。通常可自动发现电脑。
3
配对并开始搜索核对 6 位验证码，在 Windows 上批准配对。选择图库并搜索，原图流式并发传输。

局域网连接使用未加密 HTTP，只适合你自己控制的家庭专用网络，不要在公共 Wi-Fi 使用。

三步建立可持续维护的图库

先小批量验证配置和费用，再逐步扩展到完整图库

01

创建图库并确认数据边界

选择原图目录、Workspace 和结果目录，配置阿里云百炼 API Key。路径会进行安全校验，凭据不会写入配置和日志。

02

增量索引，按需智能标注

先用 qwen3-vl-embedding 建立可复用的本地向量索引，再决定是否运行独立智能标注。标注可先估算费用，缓存命中不会重复调用模型。

03

搜索、整理并持续学习

跨图库搜索后批量整理标签、别名和相似分组。相关/不相关反馈保存在本机，候选排序必须通过固定评测门禁才能启用。

本地优先，边界透明

日常文件管理、标签搜索、分页查看和多数整理操作在本机完成；需要模型理解图片时才联网

✓
原始图库位置由你决定，删除软件不会自动删除原图
✓

✓

✓

✓
