# 曜镜（YaoLens）智能图片库

YaoLens 是一款面向 Windows 的本地图片管理与智能检索软件，适合人物摄影、Cosplay、写真、动漫角色和二次元图片库。

软件使用向量检索和视觉模型理解图片内容，可以通过文字、图片、标签或图文组合快速查找目标图片。图库文件、索引和标签主要保存在本机，不需要 Docker，也不依赖复杂的命令行操作。

## 主要功能

### 智能图片检索

支持多种搜索方式：

- 文字搜索：输入人物、角色、作品、服装、场景等描述。
- 图片搜索：使用一张图片查找视觉上相似的内容。
- 图文联合搜索：同时提供图片和文字，进一步缩小范围。
- 标签搜索：按照人物、角色、作品或自定义标签查找图片。
- 跨图库搜索：同时查询多个图库，并统一整理搜索结果。

搜索数量可以自行输入。软件只返回达到最低可信度的结果，低置信度图片不会用于填满结果列表。

### 图片推荐

Windows 和 Android 都提供独立的“推荐”页面。每批目标为 15 张，由技术质量 5 张、低曝光 6 张和随机发现 4 张组成；候选不足时会降级补位或返回不足 15 张的结果，不会复制图片凑数。

推荐按 SHA-256 去重，同一图集最多 3 张、同一已确认角色最多 5 张，并按 240、210、180、150、120、90、60、30、0 的渐进窗口避开近期已看内容。多样性和个性化只复用图库已有向量，不会为了推荐临时调用模型；Windows 与每台 Android 设备分别记录曝光，并共享同一套显式喜欢/不喜欢偏好。

### 搜索质量与本地学习

搜索结果可以标记为“相关”或“不相关”。打开、复制和导出也可作为低权重反馈，由用户在设置中决定是否记录。反馈只写入本机的 `search-learning.sqlite3`，不会上传图片或调用大模型。

达到训练条件后，软件可在后台生成候选排序版本。候选版本必须通过导入的固定评测包，未配置评测包时始终保持待评测，不能直接启用。通过后可先运行影子验证，再正式启用；出现质量倒退时可以切回上一版本。

设置页会显示 Precision@15、Recall@15、无答案误报率、跨图库偏置、P95 延迟和额外 API 调用。排序模型损坏或版本不兼容时，搜索自动回退到固定排序。

### 本地图片索引

软件通过 `qwen3-vl-embedding` 为图片生成向量，并将向量写入本地 Zvec 数据库。

建立索引后，图片搜索主要在本机完成。已有向量可以重复使用，不需要每次搜索都重新调用模型。

支持：

- 新建图库并选择图片目录
- 增量建立索引
- 同步新增、修改和删除的图片
- 多图库独立管理
- 图库目录迁移与路径重新绑定
- 单张图片失败后继续处理其他图片

### 智能标注

软件使用 `qwen3-vl-flash` 分析图片并生成标签，可识别或辅助确认：

- 真人身份
- Cosplayer
- 动漫或游戏角色
- 作品名称
- 服装与造型
- 场景及其他图片信息

人工标签和文件夹名称具有更高优先级。文件夹名称会经过清理后转换成标签，图片数量、文件大小等无意义内容不会写入标签。

智能标注可以独立运行，也可以在建立索引时一并执行。已经完成且图片内容没有变化的标注会被跳过，避免重复调用模型。

### 批量标签管理

批量标签页面可以按照图库、文件夹和图片状态筛选内容，并对多张图片统一添加、删除或替换标签。

支持：

- 按文件夹选择图片
- 多选图片
- 一次添加多个标签
- 查看人工、文件夹和模型标签来源
- 批量接受模型建议
- 撤销最近一次批量操作
- 维护角色、作品和人物别名

例如可以将“雷电将军”“雷神”和“影”设置为相关别名，提高标签搜索的覆盖范围。

### 相似分组与主动学习

智能整理可以利用已有 SHA-256、感知哈希和图片向量建立重复图、近似图和语义相似分组。为避免大图库默认逐图执行向量查询，聚类默认只启用精确重复与视觉近似；内容相似可手动开启。聚类过程不重新生成向量，也不调用标注模型。

支持：

- 按精确重复、近似重复、语义相似或单图分组筛选
- 人工合并分组或拆出错误图片
- 为整组添加真人、Cosplayer、角色或作品身份标签
- 撤销最近一次分组整理
- 审核主动学习队列，并撤销最近一次审核

身份传播严格限制为真人、Cosplayer、角色和作品，不传播动作、神态、场景、镜头或构图标签。单张图片处理失败时会记录失败项并继续其余图片。

聚类快照、人工规则、审核批次和撤销状态保存在图库自己的 SQLite 状态库中。分组列表、成员和边关系均直接使用 SQLite 分页读取，不会为了打开一页而反序列化整个大图库快照。

### 搜索结果操作

搜索结果支持：

- 单击查看图片详情
- 双击调用系统程序打开原图
- 打开图片所在文件夹并定位文件
- 鼠标右键复制图片
- 多选图片
- 导出到指定文件夹
- 翻页或输入页码跳转
- 查看命中的标签和匹配来源

搜索结果会保存到设置中的结果目录。软件可以清理旧的搜索结果，只保留最近三次，不会同时删除缓存、失败图片或图库数据。

### 任务和错误处理

索引、同步和智能标注都在后台执行，界面不会因为大量图片处理而长时间失去响应。

单张图片处理失败时，软件会跳过该图片并继续完成当前批次。失败记录和可用的错误图片副本会统一保存，方便后续重新处理。

任务中心可以查看：

- 当前运行任务
- 历史任务
- 处理进度
- 成功和失败数量
- 操作日志
- 错误原因
- 后端运行状态

### 大图库性能

针对十万到百万级图片库，软件采用有界队列、磁盘分页和批量提交，避免把完整图片清单或搜索结果一次性装入内存：

- 每个图库使用独立的有界任务队列；搜索优先于长时间维护任务，不同图库可以并行处理。
- 索引扫描结果写入临时 SQLite 分页表，Collection 与状态库按批提交。异常退出后，向量写入由 Outbox 恢复且不重复调用模型；扫描临时库会经严格校验后安全清理并重新扫描。
- 桌面搜索结果按顺序写入分页结果库，界面只读取当前页的 15 张图片；翻到较后页时不需要从头加载全部结果。
- 标签搜索直接在 SQLite 中完成筛选和 Top-N 排序，不会先物化全部匹配图片。
- 元数据回填、路径迁移和大图库聚类采用 Keyset 分页与批量读取，单个坏项不会阻断整批任务。
- Collection 压缩不再绑定每次任务完成；变更累计到阈值后，仅在图库连续空闲时执行，失败会退避重试。
- 模型拒绝后的同文件夹标签继承按 500 条分页聚合，并限制单文件夹及整次任务的标签与审计内存。

用户输入的返回数量仍应与实际用途相符。极大的向量 Top-K 会增加 Zvec 查询、排序和磁盘结果集的成本，即使界面本身只显示当前页。

## 安装与启动

YaoLens 仅提供 Windows x64 版本，推荐使用 Windows 10 或 Windows 11。配套局域网查看端支持 Android 8.0 及以上版本。

### 安装版

运行 `YaoLens-0.3-win-x64-setup.exe` 并按照提示完成安装。安装版会为当前用户注册登录任务；下次登录后 YaoLens 以普通权限隐藏常驻，再次启动会唤醒已有窗口，不会重复启动后台实例。

关闭窗口只会隐藏界面，后台任务、Android LAN 服务和自动增量索引 watcher 会继续运行。需要完全停止时，使用“设置 → 应用 → 退出 YaoLens”；存在活动任务时会拒绝退出，请先等待任务完成或安全取消。

### 便携版

将 `YaoLens-0.3-win-x64-portable.zip` 完整解压到固定目录，然后运行其中的 `YaoLens.exe`。

不要直接在压缩包内启动，也不要只单独复制 EXE 文件，否则软件可能找不到前端资源或本地运行组件。

便携版不会注册登录计划任务。每次手工启动后，它只在当前登录会话内隐藏常驻；关闭窗口仍只隐藏，二次启动会唤醒已有窗口，完全停止同样使用“设置 → 应用 → 退出 YaoLens”。

### Android 局域网查看

Android 平板或手机可以在同一局域网内搜索 Windows 电脑上的图库、翻页查看结果，并打开或保存原图。电脑继续负责图库、索引和模型，Android 端不会修改桌面设置、建立索引或删除图库。

1. 在 Windows YaoLens 的“设置 → 局域网访问”中选择私网 IP，保存并启用服务。
2. 安装 `YaoLens-0.3-android.apk`，让设备与电脑连接同一 Wi-Fi。
3. Android 端通常会自动发现电脑；发现失败时可手工填写电脑的私网 IP 和端口 `38522`。
4. 两端核对相同的 6 位验证码，再在 Windows 上批准配对。
5. 在 Android 端选择图库并搜索。查询图片采用流式上传，原图采用流式并发传输。

配对不要求二维码。当前局域网连接使用未加密 HTTP，只适合你自己控制的家庭专用网络，不要在公共、共享或不可信 Wi-Fi 使用。Windows 防火墙首次提示时只允许“专用网络”；访客 Wi-Fi、AP 隔离或 VPN 可能阻止自动发现，此时应先尝试手工 IP。使用期间电脑必须保持开机，YaoLens 必须继续运行。

Android 可能要求允许“安装未知应用”。

## 首次使用

首次启动后，建议按照以下顺序操作：

1. 打开“设置”。
2. 填写阿里云百炼 API Key。
3. 检查向量模型和智能标注模型。
4. 设置搜索结果保存目录。
5. 创建一个图库并选择图片文件夹。
6. 先使用少量图片测试索引和智能标注。
7. 确认搜索效果和费用后，再处理完整图库。

模型配置可以在设置页面中维护，也可以通过独立 JSON 配置文件调整。建议使用软件提供的默认阿里云模型，避免模型维度变化导致现有索引不兼容。

## 模型说明

默认使用两个阿里云模型：

- `qwen3-vl-embedding`：负责生成文字和图片向量，用于相似度检索。
- `qwen3-vl-flash`：负责理解图片内容并生成智能标签。

模型调用受阿里云账号配额和限流影响。大批量处理时，软件会按照配置控制并发速度，但实际费用和可用额度仍以阿里云控制台为准。

普通本地搜索不会重复生成已有图片向量。智能标注、首次索引以及需要新查询向量的搜索可能产生模型调用。

## 数据与隐私

图片文件、图库索引、标签、任务历史和软件配置主要保存在本机。

提交智能标注或向量生成任务时，相关图片或查询内容会发送到所配置的阿里云模型服务。API Key 不应写入截图、日志、公开仓库或分享给其他人。

删除学习记录、操作日志、搜索结果或缓存时，不会自动删除原始图库图片，除非用户明确执行图库文件夹删除操作。

## 开发验证

大图库回归使用固定的模型替身和临时图库，不读取用户图库、不使用 API Key，也不产生模型费用。普通提交运行十万级门禁：

```powershell
python scripts/run_large_library_gates.py --profile pr --dry-run
python scripts/run_large_library_gates.py --profile pr --json-report large-library-gates.json
```

门禁覆盖搜索结果分页、扫描 staging、流式索引、标签 Top-N、大图库聚类、有界维护读取、文件夹标签继承、Collection Outbox、空闲压缩和调度背压。测试直接断言分页大小、最大物化数量和模型请求数等不变量，不使用容易受机器负载影响的绝对耗时阈值。

架构门禁还会解析生产源码，阻止重新引入全表 `list_entries()`、绕过 Outbox 的 Collection 直接写入、任务尾部同步 `optimize()`，以及桌面搜索复制或内联全部结果。后端 `/health`、`/version` 和 `backend_listening` 启动事件会输出同一份无路径、无凭据的大图库策略快照及 SHA-256，便于定位部署参数是否漂移。

百万行 staging 只在每日 Windows x64 夜间任务或人工明确启用时运行：

```powershell
$env:ZVEC_RUN_MILLION_SCAN_STAGING_TEST = "1"
python scripts/run_large_library_gates.py --profile nightly --million --json-report large-library-nightly.json
```

运行器会输出每个门禁的耗时、单行摘要和 JSON 报告；任何选中测试被跳过都会使门禁失败。Ruff、Mypy 和全量单元测试仍由主 CI 独立执行。

Android：

```powershell
cd android
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

构建需要 JDK 17、Android SDK Platform 34 和 Build Tools 34.0.0。APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`；Gradle Wrapper 不读取或生成正式发布签名密钥。

## 使用建议

- 首次使用先处理 10～50 张图片，确认配置正确。
- 大图库优先使用增量索引，不要反复重建全部向量。
- 重要人工标签应定期备份。
- 删除图库文件夹前先检查预览数量和目标路径。
- 修改向量模型前确认维度兼容性。
- 遇到失败图片时先查看错误清单，不必重新执行整个图库。
- 定期清理旧搜索结果和过期日志，避免结果目录持续增大。

YaoLens 的核心原则是：原图由用户管理，索引和标签可以重建，任何批量删除操作都应先预览、再确认、最后执行。
