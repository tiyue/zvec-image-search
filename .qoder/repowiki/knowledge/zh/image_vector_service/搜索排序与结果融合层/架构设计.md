本模块按“召回 → 融合 → 排序 → 多样性 → 导出”的分层组织：
- 召回入口：`hybrid_search.py` 负责从自然语言中识别显式/嵌入标签意图并生成 `HybridTagIntent`，再调用 `tag_search.py` 的 `TagCatalog` 解析；`metadata_search.py`、`tag_search.py`、`search_features.py` 分别处理元数据、标签与向量通道的候选。
- 融合核心：`rank_fusion.py` 实现 `weighted_rrf`（RRF）与两套置信度融合模式（`confidence_v1` / `confidence_v2`），并通过 `sort_confidence_hits` 统一过滤、截断与排序；`federated_search.py` 在多个 `LibraryCandidateSet` 间做通道级聚合与全局去重，再委托 `rank_fusion.confidence_rank` 完成最终排序。
- 后处理：`result_diversity.py` 基于文档键与 SHA256 去重并按主题分散；`search_features.py` 将 `SearchHit` 提取为版本化的 `SearchFeatures` 行供学习排序使用。
- 辅助能力：`library_browser.py` 提供只读文件夹/图片目录浏览；`source_resolver.py` + `logical_paths.py` 把 `root_id`+`relative_path` 安全解析为真实路径；`tags.py`、`tag_aliases.py`、`tag_rank_query.py`、`metadata_text.py`、`image_data_uri.py` 提供标签归一化、别名映射、文本片段提取与 Data URI 解码等工具。
依赖方向单向向下：上层编排（federated/hybrid）依赖下层融合与工具，不反向引用；所有中间结果通过不可变 dataclass（`SearchHit`、`ConfidenceRanking`、`FederatedRanking`、`SearchFeatures`）传递。
